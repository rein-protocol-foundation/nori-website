# Nori — Design

业务内容与英文文案见 [content.md](content.md)。

## 设计方向

全站采用「递归 Nori 元胞背景 + 悬浮气泡导航 + 毛玻璃、光影与 3D 层次」。本文定义设计理念、视觉语言与动态行为，以实际运行效果作为设计验证依据。

[content.md](content.md) 定义业务内容、英文文案、案例优先级和 CTA 目的地；本文定义视觉编排与交互。

## 全站视觉语言

- 小而美的独立开源产品，保留创始人的个人审美、研究者与极客气质，以及亲近的社区感。数学与计算美学承担品牌表达，产品信息必须容易理解。
- 暖白、珍珠白和浅灰为底，炭黑承担文字与深色元胞，嫩绿／苔绿用于活跃细胞与重点入口，少量暖杏光作为点缀。色彩集中、有辨识度，不使用霓虹科技感或大面积彩虹渐变。
- 方形网格与柔软玻璃形成对照：元胞保持清晰、对齐、可辨认的方格；导航、按钮和少量容器使用圆润气泡轮廓。不要把元胞本身做成不规则气泡。
- 毛玻璃具有半透明、背景模糊、细边缘高光和轻微折射感；柔和阴影、环境遮蔽与一致光源建立悬浮关系。3D 用于元胞厚度、Nori 与协作场景、玻璃表面，避免每个元素都膨胀成软胶玩具。
- 全站沿用同一套材质、光照方向、圆角层级、色彩与空间语言。下半页可以更安静，以留白和浅色实底承载密集信息，并保持统一的材质与空间层次。
- 大标题采用有性格的现代无衬线字体，少量衬线斜体作为强调；正文清晰，微型标注可用等宽字体。建立主次尺度，不用过多字体制造个性。
- 章节使用不对称构图、宽松留白和疏密变化，不把所有业务套进相同的悬浮圆角卡片。运营与金融保持同等重要，Rein 案例通过内容与空间节奏突出。

## Hero 与悬浮 Header

Hero 是一个完整、全幅的元胞自动机场景，覆盖首屏整个背景，延伸至导航与文字后方。不得采用「左文案、右侧独立插画」或把模拟放进小卡片的构图。

- 背景由 Nori 形象对应的方格构成，可超出画面裁切；大尺度轮廓包含小尺度 Nori，体现递归关系。局部元胞可有克制的挤出厚度、倒角反光和柔和投影，整体方格仍清楚。
- 标题、说明和 CTA 直接叠在背景上；文字区域通过降低元胞密度、明暗变化与局部柔化保证可读，不以大块不透明面板遮住整个场景。
- Header 是与页面顶部、两侧均有明显间距的悬浮毛玻璃胶囊。背景从其后透出，边缘高光与底部阴影表现气泡厚度；不使用贴边的全宽实色导航条。
- 导航包含 Nori 标识、必要章节入口和主行动入口；内部 CTA 可使用绿色玻璃胶囊。具体标签和目的地遵循业务内容。
- 滚动后若保持导航可见，继续保留悬浮间距与可读底色，不遮挡锚点标题。移动端缩短胶囊，允许使用可键盘操作的紧凑导航菜单；案例正文仍直接展示。
- 工作案例安排在 Hero 后的案例内容区域，完整呈现业务故事。

## 递归元胞动画

动画主线：**Nori 格子初态 → 按康威生命游戏规则演化 → 镜头持续 zoom out → 当前画面成为更大尺度初始 Nori 图案的一部分 → 继续演化与缩远，形成循环。**

- 角色辨识度优先。先看见 Nori，再发现局部细胞变化，缩远后理解自己刚刚观察的是更大 Nori 的一部分。保持连续、舒缓的尺度变化，不做突兀切镜或频繁闪烁。
- 局部演化采用 Conway B3/S23：死细胞有三个活邻居时出生；活细胞有两个或三个活邻居时存活。立体厚度、光照与颜色属于渲染层，不暗中改变状态规则。
- 递归嵌套、镜头缩放、尺度切换和循环接缝属于动画编排。不能宣称任意 Nori 初态会在康威规则下自然恢复自身、无限自复制或产生无缝递归；密集角色图案的可辨认持续时间也需实际验证。
- 实现时明确初始种子、演化步数、边界条件、嵌套倍率和接缝策略。若采用预计算片段、混合或重置，在设计／实现说明中如实记录，不能把编排后的整段描述成纯规则自然演化。
- RSI 的叙事联系是「agent 构造和改进自身能力，从而继续推进长期任务」。递归画面是该研究方向的隐喻，不是 RSI 已实现的证据；自相似、自复制与能力改进保持区别。
- 最终图案由初始种子、规则演化、观察时刻、递归层级与镜头编排共同决定，会随运行持续变化；不要求复现任何一次静态探索中的轮廓、细胞分布或嵌套位置。静态图无法验证目标动态效果，不作为逐像素还原或验收依据。
- 以实际运行的完整动画周期评价效果：角色如何进入演化、缩远如何揭示更大的 Nori、当前图案如何成为其一部分，以及下一轮如何连续接续。验证角色识别、规则演化、缩放连续性、循环接缝与阅读体验；未实现播放器前，不放置看似可用的播放按钮。
- 提供可访问的暂停／继续控制；暂停同时停止演化与镜头运动。`prefers-reduced-motion` 使用精心选择的静态递归构图，不自动缩放；离屏暂停，低性能设备可降级到同风格静态图。

## 角色、案例与全页延续

Nori 的身份特征包括薄荷粉发色、猫耳、发型轮廓、胶囊眼睛和耳机／天线。元胞初态应提炼这些特征；演化过程允许轮廓变化，通过递归缩远重新显现角色，而不是要求每一帧保持固定吉祥物形状。

- 角色与协作章节：允许较大的 Nori 元胞／3D 形象、贡献者与共享网格场景，以光影和透明连接元素表达协作。职责、具体工作和产物仍直接可见，不只展示吉祥物。
- 职位与工牌：保留职位变体的身份一致性、组织名、职位与职责。透明卡套、挂绳与金属扣采用统一的材质语言；不要求所有角色和普通页面都使用实体工牌。
- 运营、金融、社区、传播及 Rein 案例：沿用浅色空间、绿色重点、适度玻璃承载面和少量立体元素，按各自业务结构编排。实际软件工件内部保留原生比例、文字密度、准确图标与可读性，不把软件界面本身改造成玻璃玩具。
- 长期任务：表现工作遇到缺口、构造或改进能力、测试／人类协作、继续推进以及留下可复用成果。示意故事明确标识，不用装饰流程替代具体内容。
- 开源入口与页尾：回响 Hero 的递归元胞或裁切 Nori，使用统一的玻璃 CTA 与柔和光影收束，避免复制整个首屏或再次铺满繁复动画。
- 每节只在需要时使用毛玻璃容器；密集正文、金融记录与软件细节采用足够实的浅色阅读面。不要把完整 App 缩成小卡，不拉伸素材，也不膨胀图标与文字。

## 交互、可访问性与素材

核心内容直接呈现，不使用 Tab、Drawer、角色切换或折叠案例隐藏主故事。导航与 CTA 为真实链接，软件演示里的支付、发送、登录不触发真实动作。移动端导航菜单不受此案例限制。

悬浮是空间层次，不意味着所有组件持续上下漂动。动效集中在 Hero 演化／缩远和必要反馈；不靠 hover 显示重要内容、不改变布局占位。移动端保持全幅 Hero 与气泡导航，但简化元胞数量、厚度、阴影与模糊，正文按故事顺序平铺，取消影响阅读的倾斜与遮挡。

在动画各阶段检查文字和按钮对比度；玻璃模糊不能作为唯一的可读性保障。保留语义标题、键盘焦点、可操作的暂停控制和触控空间。背景画布作为装饰层，不截获导航、文字或 CTA 的操作；图形失效时仍可读完整内容。

复用适用的 Nori 与工牌身份素材，检查裁取和清晰度，不拉伸角色。正文、职位、导航和按钮使用 HTML，不把整张概念图当网页。软件工件依据准确原生界面制作，或使用获授权、脱敏截图；生成式概念画面不作为真实业务记录。无可用演示时使用明确的静态示意，不伪装可播放内容。

## 代码与检查

按章节组织实现；入口只组合页面，品牌、导航、共享基础组件与设计 tokens 分离。共享色彩、字体、玻璃材质、光照、阴影和空间层级；保留不同软件与业务的结构，避免万能组件。元胞状态更新、镜头／循环编排与渲染分离，便于分别验证。只读取当前任务所需代码与素材。

每节检查桌面和移动端实际画面、内容过程与产物、软件比例、遮挡及前后衔接。全站检查视觉语言的一致性，覆盖 Hero、各业务章节和页尾。Hero 额外检查全幅覆盖、悬浮 Header 间距、动态对比度、规则一致性、循环接缝、暂停、reduced-motion、性能与静态降级。

内容与视觉检查、构建与交互测试分别报告。文档或静态图不能证明动画成立；不以工程测试通过代替设计判断。实现时保留其他人的修改。
