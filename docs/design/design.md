# Nori — Design

业务内容与英文文案见 [content.md](content.md)。

## 视觉方向

- 黑白高对比基底、直接的产品标题、清晰的主次入口；工作画面是主体。色彩来自 Nori 身份和原生软件，不强制为背景染色。
- 保留 Nori 原始薄荷粉发色、猫耳、发型轮廓、胶囊眼睛和耳机/天线。职位变体采用金、蓝银、紫、铜红、深青等大胆发色，同时保持身份一致。
- 实体工牌保留透明卡套、黑挂绳、金属扣、员工身份照式半身构图；组织名、具体职位、职责清晰分层。普通页面只用头部，不出现工牌外的半身雕像、衣领或巨大人物陪衬。
- 一个主任务连接相关文档、日历、对话、代码任务及交付物，以轻透视、浅阴影、Z 层与少量边缘遮挡表达空间关系；重要内容始终可读。
- 完整软件界面保持原宽高比，局部按内容自然裁取。约 976×660 的产品画面可作为阅读空间参考，不强迫所有工件采用同一比例。保持原软件的文字密度与结构，使用准确品牌图标。
- 不把完整 App 缩成小卡、不膨胀图标与文字、不做软胶厚边或层层嵌套卡片。不要把不同业务全部套进同一个对话加摘要模板。
- 不使用 Listen → Coordinate 等装饰流程条、平台商标墙、巨型人物或重复整节导航。各节依据业务决定高度与密度；运营和金融同等重要，Rein 用黑白分区变化节奏。

## 交互与素材

核心内容直接呈现；不使用 Tab、Drawer、角色切换、折叠案例、View case 或装饰跳转箭头。导航与 CTA 为真实链接，软件演示里的支付、发送、登录不触发真实动作。

桌面可有克制的纵深与微动，不靠 hover 显示内容、不改变布局占位、不自动漂浮。移动端按故事顺序平铺，取消倾斜与遮挡；reduced-motion 取消位移。语义标题、键盘焦点、文字对比度与可读性必须保持。

复用现有 Nori 与工牌素材，检查裁取和清晰度，不拉伸角色。正文和职位使用 HTML，不把整张概念图当网页。软件工件依据准确原生界面制作，或使用获授权、脱敏截图；生成式概念画面不作为真实业务记录。无视频素材时呈现明确的 storyboard，不伪装可播放内容。

## 代码与检查

按章节组织实现；入口只组合页面，品牌、导航、共享基础组件与设计 tokens 分离。共享真正一致的视觉基础，保留不同软件和业务的结构，避免万能组件。只读取当前章节所需的代码与素材；分段补齐被截断的读取结果。

每节检查桌面和移动端实际画面、内容过程与产物、软件比例、遮挡及前后衔接。业务关键词出现不等于完整呈现。内容与视觉检查、构建与交互测试分别报告；保留其他人的修改，不以工程测试通过代替设计判断。
